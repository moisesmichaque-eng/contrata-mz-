### Contrata.MZ

90% dos contratos em Moçambique são verbais. Depois dá problema:
- Empregada falta e não tem prova de horário
- Pedreiro some com adiantamento
- Carpinteiro entrega MDF quando foi combinado madeira

O Contrata.MZ resolve em 3 minutos:
1. Preenche dados no telefone
2. Gera PDF com cláusulas legais (Lei nº 23/2007 + Decreto 40/2008)
3. Paga 250MT via M-Pesa
4. Recebe contrato no WhatsApp com validade legal

MVP 1: Contrato de Empregada Doméstica
MVP 2: Marketplace de profissionais verificados (BI + avaliações)

Stack: React + Supabase + Vercel (mesma do EasyPay)
